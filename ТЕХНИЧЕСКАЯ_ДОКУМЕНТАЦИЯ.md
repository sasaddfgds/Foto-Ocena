# Техническая документация проекта Foto-Ocena

## Общее описание

Foto-Ocena - веб-приложение для загрузки, просмотра и оценки фотографий пользователями. Приложение позволяет пользователям регистрироваться, загружать изображения, голосовать за них (like/dislike) и просматривать профили других пользователей.

## Технологический стек

### Backend
- **PHP 7.4+** - основной язык серверной части
- **Composer** - менеджер зависимостей
- **SQLite** - система управления базами данных (вместо запланированной MariaDB)
- **PDO** - для работы с базой данных

### Frontend
- **Vanilla JavaScript ES6** - без фреймворков
- **HTML5** - семантическая разметка с WCAG
- **CSS3** - кастомные стили с CSS переменными и анимациями

### Зависимости (composer.json)
- `vlucas/phpdotenv ^5.5` - загрузка переменных окружения из .env файла
- `guzzlehttp/guzzle ^7.8` - HTTP клиент (не используется в текущей реализации)

## Backend архитектура

### Классы в src/

#### Database.php
Singleton класс для работы с SQLite через PDO.

**Основные методы:**
- `getInstance()` - возвращает единственный экземпляр
- `getConnection()` - возвращает PDO соединение
- `query($sql, $params)` - выполнение SQL запроса
- `fetchAll($sql, $params)` - получение всех строк
- `fetchOne($sql, $params)` - получение одной строки
- `insert($table, $data)` - вставка данных
- `update($table, $data, $where, $whereParams)` - обновление данных
- `delete($table, $where, $params)` - удаление данных

**Создаваемые таблицы:**
- `users` - пользователи
- `images` - изображения
- `likes` - голоса
- `sessions` - сессии
- `rate_limits` - лимиты запросов

#### Auth.php
Класс для аутентификации и авторизации пользователей.

**Основные методы:**
- `register($username, $password)` - регистрация нового пользователя
- `login($username, $password)` - вход пользователя
- `logout()` - выход из системы
- `getCurrentUser()` - получение текущего пользователя
- `requireAuth()` - проверка авторизации
- `changePassword($userId, $currentPassword, $newPassword)` - смена пароля
- `updateAvatar($userId, $avatarPath)` - обновление аватара
- `updateProfile($userId, $username, $bio)` - обновление профиля
- `updatePrivacy($userId, $isPrivate)` - обновление настроек приватности
- `deleteAccount($userId, $password)` - удаление аккаунта

**Особенности:**
- Хеширование паролей с `password_hash()` (PASSWORD_BCRYPT, cost=12)
- Защита от timing attacks при проверке паролей
- Кеширование пользователя в сессии (5 минут TTL)
- Использование только сессий (cookie user_id удалён для безопасности)

#### ImageHandler.php
Класс для обработки и оптимизации изображений.

**Основные методы:**
- `upload($file, $userId)` - загрузка изображения
- `getPopularImages($limit, $offset)` - получение популярных изображений с пагинацией и кешированием
- `getUserImages($userId, $currentUserId)` - получение изображений пользователя (с проверкой приватности)
- `getImageById($imageId, $currentUserId)` - получение изображения по ID (с проверкой приватности)
- `getUserStats($userId)` - статистика пользователя

**Оптимизация изображений:**
- Конвертация в WebP (качество 85%)
- Ресайз до максимальных размеров (1920x1080)
- Автокоррекция яркости через imagefilter() (оптимизировано для производительности)
- Sharpen фильтр
- Сохранение прозрачности для PNG/GIF
- Кеширование популярных изображений (5 минут)

**Валидация:**
- Проверка MIME типа (JPEG, PNG, GIF, WebP)
- Максимальный размер файла: 5MB
- Проверка через `is_uploaded_file()`

#### RateLimiter.php
Класс для ограничения частоты запросов.

**Методы:**
- `check($userId, $action)` - проверка лимита

**Настройки:**
- Максимум 10 загрузок на минуту на пользователя
- Хранение в базе данных SQLite
- Автоматическая очистка старых записей

#### Security.php
Класс для безопасности приложения.

**Методы:**
- `sanitizeOutput($data)` - экранирование вывода (XSS защита)
- `sanitizeInput($data)` - очистка входных данных
- `generateCsrfToken()` - генерация CSRF токена
- `validateCsrfToken($token)` - валидация CSRF токена
- `setSecurityHeaders()` - установка security headers
- `validateJsonInput()` - валидация JSON Content-Type
- `rateLimitCheck($identifier, $maxRequests, $window)` - проверка rate limit
- `checkAuthRateLimit($ip, $username)` - проверка rate limit для авторизации (5 попыток, блок на 5 минут)

**Security Headers:**
- Content-Security-Policy (без unsafe-inline для scripts)
- X-Content-Type-Options: nosniff
- X-Frame-Options: DENY
- X-XSS-Protection: 1; mode=block
- Strict-Transport-Security (только при HTTPS)
- Referrer-Policy: strict-origin-when-cross-origin
- Permissions-Policy: geolocation=(), microphone=(), camera=()

## API Endpoints

### Аутентификация

#### POST /api/login.php
Вход пользователя.

**Request Body:**
```json
{
  "username": "string",
  "password": "string"
}
```

**Response:**
```json
{
  "message": "Zalogowano pomyślnie",
  "user": {
    "id": 1,
    "username": "string",
    "avatar": "string|null",
    "bio": "string",
    "is_private": 0
  },
  "user_id": 1
}
```

#### POST /api/register.php
Регистрация нового пользователя.

**Request Body:**
```json
{
  "username": "string (3-50 символов)",
  "password": "string (минимум 6 символов)"
}
```

**Response:**
```json
{
  "message": "Rejestracja zakończona pomyślnie",
  "user_id": 1,
  "user": { ... }
}
```

#### POST /api/logout.php
Выход из системы.

**Response:**
```json
{
  "message": "Wylogowano pomyślnie"
}
```

#### GET /api/user.php
Получение текущего пользователя.

**Response:**
```json
{
  "user": { ... } | null
}
```

### Изображения

#### GET /api/images.php
Получение изображений.

**Query Parameters:**
- `type` - тип запроса: `popular`, `user`, `single`
- `limit` - лимит (для type=popular, по умолчанию 20)
- `user_id` - ID пользователя (для type=user)
- `id` - ID изображения (для type=single)

**Response (type=popular):**
```json
{
  "images": [
    {
      "id": 1,
      "user_id": 1,
      "filename": "string",
      "file_path": "uploads/string",
      "likes": 10,
      "dislikes": 2,
      "username": "string",
      "avatar": "string|null"
    }
  ]
}
```

#### POST /api/upload.php
Загрузка изображения.

**Request:** FormData с полем `image`

**Requirements:**
- Авторизованный пользователь
- Rate limit: 10 загрузок в минуту
- Максимальный размер: 5MB
- Форматы: JPEG, PNG, GIF, WebP

**Response:**
```json
{
  "message": "Zdjęcie przesłane pomyślnie",
  "image": {
    "image_id": 1,
    "filename": "string",
    "file_path": "uploads/string",
    "width": 1920,
    "height": 1080
  }
}
```

#### POST /api/upload-avatar.php
Загрузка аватара.

**Request:** FormData с полем `avatar`

**Requirements:**
- Авторизованный пользователь
- Максимальный размер: 2MB
- Форматы: JPEG, PNG, GIF, WebP

**Response:**
```json
{
  "message": "Avatar zaktualizowany",
  "avatar": "uploads/avatars/string"
}
```

### Голосование

#### POST /api/like.php
Голосование за изображение.

**Request Body:**
```json
{
  "image_id": 1,
  "is_like": 1  // 1 = like, 0 = dislike
}
```

**Response:**
```json
{
  "message": "Głos dodany",
  "action": "added"  // "added", "changed", "removed"
}
```

**Логика:**
- Один пользователь может голосовать один раз за изображение
- Повторный голос с тем же значением удаляет голос
- Повторный голос с другим значением изменяет голос

### Настройки

#### GET /api/settings.php
Получение настроек пользователя.

**Response:**
```json
{
  "user": { ... }
}
```

#### POST /api/settings.php
Обновление настроек.

**Request Body:**
```json
{
  "action": "change_password|update_profile|update_privacy|delete_account",
  // ... дополнительные поля в зависимости от action
}
```

**Actions:**
- `change_password`: `current_password`, `new_password`
- `update_profile`: `username`, `bio`
- `update_privacy`: `is_private`
- `delete_account`: `password`

### Real-time

#### GET /api/events.php
Server-Sent Events для real-time обновлений.

**Events:**
- `likes_update` - обновление лайков
- `new_images` - новые изображения

**Примечание:** SSE реализован на сервере, но отключен в клиентском коде (return в setupSSE в app.js)

## Схема базы данных

### Таблица users
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL UNIQUE,
    password_hash TEXT NOT NULL,
    avatar TEXT DEFAULT NULL,
    bio TEXT DEFAULT NULL,
    is_private INTEGER DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```

### Таблица images
```sql
CREATE TABLE images (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    filename TEXT NOT NULL,
    original_filename TEXT NOT NULL,
    file_path TEXT NOT NULL,
    width INTEGER NOT NULL,
    height INTEGER NOT NULL,
    file_size INTEGER NOT NULL,
    likes_count INTEGER DEFAULT 0,
    dislikes_count INTEGER DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
)
```

### Таблица likes
```sql
CREATE TABLE likes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    image_id INTEGER NOT NULL,
    is_like INTEGER NOT NULL DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (image_id) REFERENCES images(id) ON DELETE CASCADE,
    UNIQUE(user_id, image_id)
)
```

### Таблица sessions
```sql
CREATE TABLE sessions (
    id TEXT PRIMARY KEY,
    user_id INTEGER NOT NULL,
    ip_address TEXT,
    user_agent TEXT,
    last_activity DATETIME DEFAULT CURRENT_TIMESTAMP,
    expires_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
)
```

### Таблица rate_limits
```sql
CREATE TABLE rate_limits (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    action TEXT NOT NULL,
    request_count INTEGER DEFAULT 1,
    window_start DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    UNIQUE(user_id, action, window_start)
)
```

## Безопасность

### Реализованные меры

1. **XSS защита:**
   - `htmlspecialchars()` для вывода
   - `strip_tags()` для входных данных
   - Content-Security-Policy header (без unsafe-inline для scripts)

2. **CSRF защита:**
   - Генерация токенов в сессии
   - Валидация токенов при POST запросах
   - `hash_equals()` для сравнения

3. **SQL Injection защита:**
   - Prepared statements через PDO
   - Параметризованные запросы
   - Whitelist для имён таблиц в Database.php

4. **Аутентификация:**
   - Хеширование паролей (PASSWORD_BCRYPT, cost=12)
   - Защита от timing attacks при проверке паролей
   - Сессии с lifetime
   - Удаление небезопасного cookie user_id (используются только сессии)

5. **Rate Limiting:**
   - 10 загрузок в минуту на пользователя
   - 5 попыток авторизации на IP+username, блок на 5 минут
   - Хранение в базе данных и сессиях
   - Автоматическая очистка

6. **File Upload безопасность:**
   - Проверка `is_uploaded_file()`
   - Валидация MIME типа через finfo
   - Ограничение размера файла
   - Генерация уникальных имён файлов
   - .htaccess защита в uploads/ от выполнения скриптов

7. **Security Headers:**
   - CSP (без unsafe-inline для scripts)
   - X-Frame-Options: DENY
   - X-XSS-Protection: 1; mode=block
   - HSTS (при HTTPS)
   - Referrer-Policy: strict-origin-when-cross-origin
   - Permissions-Policy: geolocation=(), microphone=(), camera=()

8. **Защита базы данных:**
   - База данных перемещена из публичной директории в корень проекта
   - .htaccess защита в public/api/ от доступа к .db файлам
   - Безопасное логирование (без чувствительных данных)

9. **Безопасное логирование:**
   - Убрано логирование SQL ошибок с деталями
   - Убрано логирование деталей файлов при загрузке
   - Убрано логирование сессий и пользовательских данных

10. **Проверка приватности:**
    - getUserImages() и getImageById() проверяют is_private пользователя
    - Приватные профили скрыты от других пользователей
    - Владелец видит свои фото даже в приватном режиме

11. **Оптимизация производительности:**
    - Автокоррекция яркости через imagefilter() вместо перебора пикселей
    - Кеширование популярных изображений (5 минут)
    - Пагинация для популярных изображений

12. **Удаление дубликатов кода:**
    - Общий ApiClient (синглтон) вместо 3 копий
    - CSRF методы только в Security.php
    - Общий Dropdown компонент
    - Общие утилиты для форм

13. **Безопасность данных:**
    - Полный отказ от localStorage в пользу сессий
    - Данные пользователя хранятся только на сервере

## Несоответствия между планом и реализацией

### 1. База данных
**План (projekt.md):** MariaDB 10.3+ с phpMyAdmin
**Реализация:** SQLite

**Влияние:** SQLite проще в настройке, но менее масштабируем. Нет необходимости в отдельном сервере БД.

### 2. Хранение изображений
**План (projekt.md):** Изображения хранятся в GitHub репозитории, backend имеет токен для API
**Реализация:** Изображения хранятся локально в папке `uploads/`

**Влияние:** 
- Нет интеграции с GitHub API
- Backend не имеет токена для GitHub
- Frontend не получает изображения напрямую из GitHub
- Изображения хранятся на локальном сервере

### 3. Real-time обновления
**План (projekt.md):** SSE для real-time обновлений
